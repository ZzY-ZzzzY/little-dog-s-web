2. 双击 zhang-0302-work2.html，或使用 VS Code Live Server 打开。
3. 页面顶部“播放音乐”按钮用于启动/暂停背景音乐。
4. 图片链接打开 club_intro.html；该页按钮可返回主页。
5. 报名表目前为前端演示，不会把资料发送到服务器。
